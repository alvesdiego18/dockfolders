Suas pastas de projeto, a um clique do Dock.

O DockFolders abre um balão no Dock com suas pastas e grupos de projeto. Cada pasta abre no Finder, no Terminal, no Xcode ou no app que você escolher.

Recursos

Feito para quem alterna entre muitos projetos durante o dia.

Mora no Dock

Um clique no ícone abre o balão ancorado a ele. Clicar fora, clicar de novo ou pressionar Esc fecha.

Pastas e grupos

Pastas soltas no topo e grupos abaixo. Junte num grupo o app iOS, o app Android e o backend do mesmo produto.

Sem barra de rolagem

Abrir um grupo fecha os outros. O balão continua compacto, não importa quantos grupos você tenha.

Arrastar e soltar

Mova pastas entre grupos e reordene as aberturas arrastando. Um grupo fechado se abre quando você para sobre ele.

Invisível em chamadas

O conteúdo do balão não aparece no Meet, no Teams nem em gravações de tela. Seus caminhos de projeto ficam só com você.

O grupo recente sobe

Ao reabrir o balão, o último grupo usado vai para o topo. Ele também pode iniciar junto com o macOS.

Aberturas

Cada pasta abre do jeito que o projeto pede.

Uma abertura é um app vinculado à pasta. O clique no nome usa a primeira da lista. As demais aparecem quando você passa o mouse sobre a pasta.

  • A pasta inteiraToda pasta nova começa com o Finder como principal e o Terminal como segunda opção.
  • Um arquivo específicoO Xcode precisa do .xcworkspace, não da pasta. A abertura pode apontar direto para ele.
  • Terminal com comandoAbre o Terminal na pasta e já executa um comando, como claude ou npm run dev.
  • Qualquer outro appVS Code, Android Studio, Fork, Cursor… Escolha em /Applications com o botão +.
~/Library/Application Support/DockFolders/folders.json
// trecho de exemplo
{
  "path": "/Users/ana/dev/loja/loja-ios",
  "openers": [
    {
      "bundleID": "com.apple.dt.Xcode",
      "targetPath": "/Users/ana/dev/loja/loja-ios/Loja.xcworkspace"
    },
    {
      "bundleID": "com.apple.Terminal",
      "command": "claude"
    },
    { "bundleID": "com.microsoft.VSCode" }
  ]
}

Instalar

Dois caminhos para começar.

Pelo instalador

  1. Baixe o DockFolders.dmg (sempre a versão mais recente). Versões anteriores ficam em Releases.
  2. Abra o .dmg e arraste o DockFolders.app para Applications.
  3. Na primeira abertura, libere o app no Gatekeeper.
  4. Botão direito no ícone do Dock → Opções → Manter no Dock.
Por que o macOS avisa na primeira abertura? O app tem só assinatura local, sem Developer ID nem notarização da Apple. Para liberar, clique com o botão direito no app e escolha Abrir. Outra opção é ir em Ajustes do Sistema → Privacidade e Segurança → Abrir Mesmo Assim.

A partir do código-fonte

Precisa apenas do Xcode ou das Command Line Tools. O projeto não tem dependências externas.

Terminal
git clone https://github.com/alvesdiego18/dockfolders.git
cd dockfolders
./DockFolders/build.sh

O script gera o DockFolders.app e o instalador .dmg em DockFolders/dist/.

Nada sai do seu Mac.

O DockFolders não se conecta à internet e não coleta dados. Toda a configuração fica num único arquivo JSON local, que você pode ler e editar à mão.

Seu arquivo nunca é descartado.

Se o folders.json estiver corrompido, o app guarda uma cópia como folders.json.corrupt-<timestamp> antes de recomeçar com a lista vazia.
